# Security policy

## Supported versions

Until the first release, security fixes are made on the default branch. After releases begin, this file will list the supported release lines.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository. Do not open a public issue for an unpatched vulnerability and do not include credentials, tokens, tenant details, or other sensitive data in a report.

Include the affected code, reproduction steps, impact, and any suggested fix. The maintainer will acknowledge the report, assess it, and coordinate disclosure after a fix is available.
